## Level 0 · Calypso's Loom

### State

*Where the agent is: everything about the situation that matters for what happens next.*

- **Story.** Before you choose a heading, you must know where you stand.
- **Intuition.** The state describes the current situation. On Calypso's loom it is just the raft's cell: one of 25. Every decision is made from a state, and every action leads to a new one.
- **Math.** The state space S is the set of all states. Here S = {0, …, 24}, the cell index y · 5 + x.
- **Further reading.** Sutton & Barto, Reinforcement Learning: An Introduction (2nd ed., 2018), §3.1

### Action

*What the agent does: one choice from the moves allowed in the current state.*

- **Story.** North, east, south or west: every stroke is a choice.
- **Intuition.** An action is one decision. The raft has four, one per compass direction. Rowing into the edge is allowed, but the raft does not move and the stroke is wasted.
- **Math.** The action space A = {north, east, south, west}. The environment's dynamics give the next state s′ from the current state s and the action a.
- **Further reading.** Sutton & Barto (2018), §3.1

### Reward

*The number the environment pays for one action, the moment it is taken.*

- **Story.** Every stroke costs strength. The shore repays it.
- **Intuition.** After each action the environment pays a reward: −1 for every move, +10 for reaching the shore. A reward judges one move only. It says nothing directly about whether the voyage as a whole is going well.
- **Math.** The reward r_{t+1} = R(s_t, a_t, s_{t+1}) is a real number. Here r = −1 per step, plus 10 on reaching the goal.
- **Further reading.** Sutton & Barto (2018), §3.1–3.2

### Return

*Every reward of an episode added up: the score a whole voyage is judged by.*

- **Story.** A good voyage is not one good stroke. It is the sum of all of them.
- **Intuition.** The return adds up the rewards from launch to shore. A single reward can look bad while the return is good: each move pays −1, but moving is the only way to collect the +10. An agent tries to make the return large, not each reward.
- **Math.** G = r_1 + r_2 + … + r_T. The shortest voyage on the loom takes 8 moves, so the best return is −8 + 10 = 2. Later levels discount future rewards: G = Σ_k γ^k r_{k+1}.
- **Further reading.** Sutton & Barto (2018), §3.3

### Episode

*One voyage from start to end: reaching the goal, failing, or running out of time.*

- **Story.** Every voyage ends: at the shore, in a whirlpool, or when the day runs out.
- **Intuition.** An episode is one complete run from the start state until it terminates (the goal or a failure) or is truncated by the step limit. Each episode starts fresh from a seed, so episodes can be repeated exactly.
- **Math.** An episode is a trajectory s_0, a_0, r_1, s_1, …, s_T. Termination ends it for good; truncation only stops it, so learning still treats the last state as having a future.
- **Further reading.** Sutton & Barto (2018), §3.4

### Agent and environment

*The agent chooses actions; the environment answers each one with a new state and a reward.*

- **Story.** You were the agent on the loom. From now on, something else rows.
- **Intuition.** Reinforcement learning splits the world in two: the agent, which decides, and the environment, which responds. They meet in a loop: state, action, reward, new state, again and again until the episode ends.
- **Math.** This loop is a Markov decision process (S, A, P, R): transitions P(s′ | s, a) and rewards R(s, a). The agent's goal is to maximise the expected return.
- **Further reading.** Sutton & Barto (2018), ch. 1 and §3.1

## Level 1 · The Raft

### Policy

*The agent's rule for choosing an action in each state.*

- **Story.** A raft with no memory drifts wherever the waves push it.
- **Intuition.** A policy says what the agent does in each state. The random agent's policy picks any direction with equal chance and ignores the state completely. Learning means improving the policy.
- **Math.** A policy π(a | s) is a probability of each action in each state. The random policy is π(a | s) = 1/4 for all s and a. A greedy policy picks argmax_a Q(s, a).
- **Further reading.** Sutton & Barto (2018), §3.5

### Seeds and reproducibility

*A seed fixes all randomness, so the same seed always gives the same episode.*

- **Story.** Among a hundred drifting rafts, one looks like a master sailor. Ask it to sail again, on a new sea.
- **Intuition.** Every episode is driven by a seed. The same seed replays the same voyage exactly, which makes experiments repeatable. But the best of many seeds is luck, not skill: a policy must do well on seeds it has never seen.
- **Math.** The maximum of n samples grows with n even when nothing improves. That is why results are reported on fixed test seeds, never on the best training seed.
- **Further reading.** Henderson et al., Deep Reinforcement Learning that Matters (AAAI 2018)

### Q-value and Q-table

*Q(s, a): how much return the agent expects from taking action a in state s and acting well afterwards.*

- **Story.** A good sailor remembers which stroke paid off in each stretch of water.
- **Intuition.** A Q-value scores one move in one state. A Q-table holds one Q-value for every state and action: 25 cells × 4 moves = 100 numbers on the raft's sea. The best move in a state is the one with the highest Q-value.
- **Math.** Q^π(s, a) = E[G_t | s_t = s, a_t = a, then follow π]. The optimal values Q* satisfy Q*(s, a) = E[r + γ max_a′ Q*(s′, a′)].
- **Further reading.** Sutton & Barto (2018), §3.5–3.6

### Q-learning

*Nudge Q(s, a) toward the reward plus the best value of the next state, after every move.*

- **Story.** After every stroke the raft changes one number in its memory, a little.
- **Intuition.** Q-learning learns from each move as it happens. It compares what it expected, Q(s, a), with a better guess: the reward it just got plus the value of the best move from where it landed. Then it moves Q(s, a) part of the way toward that guess.
- **Math.** target = r + γ · max_a′ Q(s′, a′), or just r when the episode terminated. Q(s, a) ← Q(s, a) + α · (target − Q(s, a)). The difference target − Q(s, a) is the temporal-difference error.
- **Further reading.** Sutton & Barto (2018), §6.5; Watkins, Learning from Delayed Rewards (PhD thesis, 1989)

### Exploration: ε-greedy

*With probability ε take a random move, otherwise the move with the highest Q-value.*

- **Story.** A sailor who only takes known routes never finds a shorter one.
- **Intuition.** If the raft always took its current best move, it would never try the moves it has not learned about. ε-greedy explores on purpose: a small share of moves are random. That is why training returns look worse than deployed ones.
- **Math.** π(a | s) = 1 − ε + ε/|A| for the greedy action, and ε/|A| for each other action. Q-learning learns the greedy policy's values while following this exploring one.
- **Further reading.** Sutton & Barto (2018), §2.2–2.3

### Learning rate α

*How far each update moves a Q-value toward its target, from 0 (not at all) to 1 (all the way).*

- **Story.** A quick learner forgets as quickly; a slow one needs many voyages.
- **Intuition.** α sets the size of each correction. A large α learns fast but is pushed around by every surprise. A small α averages over many experiences but needs more of them.
- **Math.** Q ← Q + α (target − Q) = (1 − α) Q + α · target: an exponential moving average of targets, with weight α on the newest.
- **Further reading.** Sutton & Barto (2018), §2.4–2.5

### Discount γ

*How much a reward counts for each step it lies in the future, from 0 (only now) to nearly 1.*

- **Story.** A short-sighted raft cannot see the shore past the next wave.
- **Intuition.** γ shrinks future rewards. With γ = 0.1 the +10 at the shore is almost invisible from a few moves away, so far cells all look the same and the raft wanders. With γ = 0.95 the shore's pull reaches every cell.
- **Math.** G_t = Σ_k γ^k r_{t+k+1}. With every move costing −1, a cell far from the goal is worth about −1/(1 − γ): −1.11 at γ = 0.1, nearly the same everywhere.
- **Further reading.** Sutton & Barto (2018), §3.3

### Training and deployment

*Training explores; deployment tests the greedy policy on fixed seeds it never trained on.*

- **Story.** Practice in the harbour, then sail for real.
- **Intuition.** During training the agent explores and its returns include random moves. Deployment switches exploration off and sails fixed test seeds. Only deployment results say what the agent can actually do.
- **Math.** Deployment evaluates the greedy policy π(s) = argmax_a Q(s, a) on held-out seeds: an estimate of its expected return without exploration noise.
- **Further reading.** Sutton & Barto (2018), §6.5

## Level 2 · The Lotus-Eaters

### Reward design

*Choosing the reward weights is choosing what the agent will want.*

- **Story.** The crew wants what the sea rewards, nothing more.
- **Intuition.** The agent maximises exactly the reward it is given. Rocks, whirlpools, the lotus and the shore each have a weight, and the weights decide which route is best. Say what you want, not how to get it.
- **Math.** The reward is a weighted sum of terms: r = Σ_i w_i · φ_i(s, a, s′). Changing a weight w_i changes which policy is optimal.
- **Further reading.** Sutton & Barto (2018), §3.2; Ng, Harada and Russell, Policy invariance under reward transformations (ICML 1999)

### Reward hacking

*The agent finds a way to collect reward that its designer did not intend.*

- **Story.** Whoever tastes the lotus forgets home.
- **Intuition.** If staying in the lotus pays more than going home, the agent stays forever. If dying is cheaper than rowing, it dives into a whirlpool. Neither is a bug in the agent: it did what the reward asked.
- **Math.** With a lotus reward of +5 and a step cost of −1, staying is worth about 4 / (1 − γ) = 80 at γ = 0.95, more than the discounted value of the shore.
- **Further reading.** Amodei et al., Concrete Problems in AI Safety (2016), §3; Krakovna et al., Specification gaming examples in AI (DeepMind blog, 2020)

## Level 3 · The Cyclops' Cave

### State and observation

*The observation is the part of the state the agent actually sees; it may leave out what matters.*

- **Story.** The raft is not blind. It simply was never told where to look.
- **Intuition.** The true state of the cave is where the raft is and where Polyphemus is. The raft observes only what its observation includes. Situations that look the same to it share one row of the Q-table, and so share one best move.
- **Math.** The agent sees o = f(s), not s. Tabular Q-learning learns Q(o, a); if f merges states that need different actions, no table over o can act well in both.
- **Further reading.** Sutton & Barto (2018), §17.3; Kaelbling, Littman and Cassandra, Planning and acting in partially observable stochastic domains (1998)

### The Markov property

*What happens next depends only on the current state and action, not on the history.*

- **Story.** A good chart tells you everything you need to plot the next leg.
- **Intuition.** A state has the Markov property when knowing it is enough: the past adds nothing. Q-learning relies on it. If the observation leaves out something that drives the future, like a hunting giant, the observation is not Markov.
- **Math.** P(s_{t+1}, r_{t+1} | s_t, a_t) = P(s_{t+1}, r_{t+1} | s_0, a_0, …, s_t, a_t). The raft's position alone violates it in the cave: the next reward depends on Polyphemus too.
- **Further reading.** Sutton & Barto (2018), §3.1

### The size of a Q-table

*One row per distinct observation: the product of each feature's number of values.*

- **Story.** Every extra thing a sailor watches is something more to learn.
- **Intuition.** Adding a feature multiplies the table. Polyphemus' direction makes 49 × 5 = 245 rows; his exact position makes 49 × 49 = 2,401. Every row must be visited to be learned, so a bigger table needs more training. The right feature carries what the decision needs, and little else.
- **Math.** |S_obs| = ∏_i c_i for discrete features with c_i values each. The table holds |S_obs| · |A| numbers. Its growth with the number of features is the curse of dimensionality that function approximation (Level 7) answers.
- **Further reading.** Sutton & Barto (2018), §9.1; Bellman, Dynamic Programming (1957)

### A fair experiment

*Change one setting, keep everything else (seed, budget, other settings) the same, and compare on fixed test seeds.*

- **Story.** Calypso trusts experiments, not stories.
- **Intuition.** To know what a setting does, run two experiments that differ only in that setting. Same seed, same budget, same test seeds. Then any difference in the results was caused by that setting. Rerun a specification to check it reproduces exactly.
- **Math.** A specification fixes the seed, the settings and the test seeds, so a run is a deterministic function of it. Comparing two runs that differ in one input isolates that input's effect, up to the variation across seeds, which more seeds can measure.
- **Further reading.** Henderson et al., Deep Reinforcement Learning that Matters (AAAI 2018)
